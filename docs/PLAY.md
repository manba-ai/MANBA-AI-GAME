# Play 使用说明

## 打开与操作

双击项目根目录的 `play.html`，选择或拖入生成的 `.edgegame` 文件，等标题出现后点击“开始 / 继续”。分享时将这两个文件一起发送。

Play 在本机读取游戏，页面已包含运行器、位图解码和音频，不需要联网或启动服务。

| 输入 | 功能 |
| --- | --- |
| 方向键 / WASD | 方向 |
| L / K / I / J | A / B / X / Y |
| Space | 游戏设置的主动作 |
| P / R | 暂停 / 重开 |
| 屏幕按键 | 鼠标或触摸操作 |
| 浏览器识别的标准手柄 | 连接后按一次按键 |

先点击画面再使用键盘。按键的具体作用以游戏提示为准。切换窗口会释放按键并暂停，返回后点击“开始 / 继续”。“重新载入”从头加载当前文件；选择另一游戏时会停止原游戏及声音。

声音需要点击页面后启用。成绩使用浏览器的本地存储；换浏览器、移动页面、隐私模式或清理数据可能影响保存。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 页面空白或无法加载 | 完整解压，确认打开的是根目录 `play.html`；浏览器需要支持 Wasm 和 Worker。读取页面显示的具体错误。 |
| 游戏停在标题 | 点击“开始 / 继续”，或按 A/Space。 |
| 没有声音 | 点击画面，检查声音按钮是否开启，并检查系统音量。 |
| 按键或手柄没反应 | 点击画面取得焦点；手柄连接后按一次按钮，检查浏览器是否识别。 |
| 页面或游戏脚本报错 | 记录完整错误、来源、行号、浏览器名称，以及打开页面还是选包后出现。关闭旧标签页后重新打开再试。 |
| 控制台报错来源为 `chrome-extension://` 等扩展地址 | 这是浏览器扩展脚本；如影响操作，停用对应扩展后重试。 |

试玩时检查导入、开始、移动与动作、暂停恢复、重开、胜负和声音。反馈问题时附上游戏包、操作步骤和页面错误。
