# 游戏包规格与运行限制

游戏包格式为 `edge.game/1`，SDK 版本为 `1`。画布固定为 320×240，颜色采用 RGB565。机器可读定义见 [契约 JSON](../contracts/km013-st7789-i8080-v1.json)。

| 限制 | 默认 legacy | resources-v2（显式选择） |
| --- | ---: | ---: |
| 游戏包 JSON | 512 KiB | 2 MiB |
| 编译后的 Lua | 128 KiB | 256 KiB |
| Lua 内存 | 512 KiB | 1 MiB |
| 位图数量 | 64 | 256 |
| 含高清位图的图集源像素 | 196,608 | 786,432 |
| 独立位图资源池 | 计入 Lua 内存 | 1 MiB |

每次回调最多 250,000 条指令，单步时间不超过 50ms，每帧最多 300 条绘制、230,400 位图工作像素。建议常规场景控制在 120 条绘制以内。压力测试还需检查加载峰值、长局和多次重开。

高清单图最多 128×128、256 个 RGB565 调色板槽位、16 级透明度，使用 `indexed8-alpha4` 编译，GameSpec 设置 `bitmap_compression: "zlib"`。压缩仅减少存储，运行时解压后的图集和绘制工作量仍计入预算。旧 indexed4 单图 64×64、图集合计 49,152 像素。

`graphics-v2` 支持批量精灵、tilemap 和背景缓存，需显式声明。上限为 256 项批量精灵、16 张 tilemap / 16,384 格、2 张背景缓存 / 307,200 字节。接口见 SDK 的 `docs/ENGINE_V2.md`。

方向键和动作键支持事件与持续输入；持续输入超过 400ms 未刷新即释放。ABXY 使用命名事件。绘制文本采用 5×7 ASCII 字体，单条最多 96 字节，字号 1～4。中文名称和说明可用于 Play 页面。
