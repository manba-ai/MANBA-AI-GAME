# 游戏素材

游戏素材尺寸如下。游戏图标和启动页分别准备，保持同一套画面风格。

| 用途 | 交付/编译尺寸 | 构图与存放 |
|---|---|---|
| 游戏素材 | 实际显示大小，单图 ≤128×128 | 独立角色、环境、道具、动作/VFX；编译进游戏图集 |
| 游戏列表 ICON | 80×80，仅此一个版本 | 1:1；清晰单主体、简洁主题背景、不透明、无文字；包内 assets.launcher_icon |
| 游戏启动页 | 320×240 | 主题插画、可读英文标题、动态菜单；明确 A 后开局；包内 |

不要从同一张启动页机械缩放生成全部用途。风格、身份、道具一致，但构图分别适配。字体不清楚时用可控排版补字，并再次查看成图。PNG 要完整解码，无水印与意外边框。

## 素材清单

```json
{"format":"bitmap-pack/1","sprites":[
  {"name":"hero_idle","file":"hero_idle.png","size":[32,48],
   "encoding":"indexed8-alpha4","transparent":true,"trim":false,
   "resample":"lanczos","pivot":[16,48],"role":"player"}
],"animations":{"idle":{"frames":["hero_idle"],"frame_ms":100,"loop":true}}}
```

动画共享画布、比例、光向与锚点；裁透明空白要保存偏移，不能让脚底和碰撞位置跳动。插画缩小可 Lanczos，既有像素画用 nearest。量化后在 1× 游戏尺寸看主体/半透明边缘，也检查放大图。编译器输出的 bindings.json 含 `bitmaps`、`sprite_manifest` 和 data 名称、锚点、动画，完整合入 GameSpec。

游戏内完整背景按原生 320×240 分块，不通过放大低分辨率图宣称高清。透明特效使用 alpha4，不默认黑底相加；SDK 不提供的混合模式不要假定存在。

一张 320×240 启动图占 76,800 源像素；建议在设计时预留图集空间。ICON 不占游戏图集，但占完整包体。每张 indexed8 图常驻约 width×height+768 字节加对象开销；压缩只减存储。到硬限制之前先查未使用资源、重复图块、运行分配、过度绘制，不自动减色/改动画/降分辨率。
